# SP7 Logistics Website Development

A responsive website prototype developed for SP7 Logistics in collaboration with a real client.
I continuously communicated with the client to gather the projects requirements, and design and implement a website suited to the clients needs. 
I used an interactive process based on stakeholder feedback to refine features and design decisions.

With a simple front-end built using HTML, CSS, and JavaScript I created a multi-page website to successfully meet the projects requirements. 
This is supported by a Node.js/Express backend to process customer enquiries and securely relay contact-form submissions via email.
